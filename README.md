# Comic Collection Tracker

SQL database to track and analyze a comic book collection, built with SQLite and populated via the Comic Vine API. 
Semi vibe-coded and reverse-engineered Python script for the API call with Claude. 

Preferred to call real data instead of making it up and populating it all manually, with the exception of a few fields like "condition" or "estimated value" which aren't naturally part of the set, and which I added manually.
